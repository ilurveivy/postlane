# 示例导入文件

`sample-leads.csv` 和 `sample-leads.xlsx` 内容相同，用来验证导入流程。**里面全是 `example.com` 的假地址，
发不出去也打不到人**，可以随便试。

列结构：

| 列               | 必需 | 说明                   |
| ---------------- | ---- | ---------------------- |
| `business_email` | ✅   | 收件人地址             |
| `email_subject`  | ✅   | 主题，可用 `{{变量}}`  |
| `email_content`  | ✅   | 正文，可用 `{{变量}}`  |
| `姓名` / `公司`  | —    | 任意额外列都会变成变量 |

正文里写了 `{{姓名}}`、`{{公司}}`，导入后每个收件人会看到各自那一行渲染出来的内容。

想自己造数据时注意：

- 一行一封邮件；
- CSV 用 UTF-8；
- 主题和正文要**逐行不同**，完全重复的内容会在提交时被拦下（避免误发群发信）。
