# 导入地址预检

导入 Excel/CSV、选定邮箱列之后，可以点「检查地址」先跑一次域名预检。结果分三类，
**只提示、不改写地址**。

## 三类结果

| 结果         | 含义                                                                                        | 处理                                       |
| ------------ | ------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 明确无效     | 格式错误、在停发名单里、域名不存在（NXDOMAIN）、Null MX、既没有 MX 也没有备用的 A/AAAA 路由 | 排除，并记入异常记录                       |
| 存在风险     | DNS 超时/失败、预检总预算内没算完、只有备用路由、常见拼写错误（如 `gmial.com`）             | 保留，不自动改写                           |
| 暂未发现问题 | 域名有邮件路由                                                                              | 保留；**不代表邮箱真实存在，也不保证送达** |

计数按规范化后的**唯一邮箱**，不是 Excel 行数。

## 在哪里生效

普通导入、自动分组、编排提交时都会执行检查；编排**预览**也会执行，所以预览看到的就是提交时的判断。

预检只做 DNS 查询：不做 SMTP 邮箱枚举、不发验证邮件、不接第三方地址验证服务。

## 预算与缓存

- 总体预算 8 秒，最多 8 个并发域名查询，单域名最多 2.5 秒；
- 缓存最多 2,000 个域名，确定性结果缓存 5 分钟、风险结果 30 秒；
- 预算内没算完的地址一律标为「存在风险」，**绝不标成通过或无效**。

`PREFLIGHT_DNS=disabled` 会把所有结果标记为未知，只用于测试环境；不要在生产里设置。

## 数据保护

- 新导入的原始行随 import-source 快照保存，包含被排除的记录和原始标题、正文；
- 预检排除的规范化联系人另外保存在名单的 `preflight.excluded` 里；
- 全表都被排除时不会创建任务，原始文件仍然是来源；
- 历史数据不回填、不删除；已安排的任务不会被追溯更改。

## 局限

预检反映的是**导入或编排那一刻**的域名状态，无法预测之后的域名变更、邮箱停用、容量变化，
也无法预测基于内容或发件人信誉的拒收。它只能帮你筛掉明显发不出去的地址。
